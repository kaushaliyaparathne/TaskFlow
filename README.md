# 📋 TaskFlow - Task Management System

TaskFlow is a full-stack task management web application that helps users create, organize, update, and manage daily tasks efficiently. The application provides secure user authentication, task status tracking, dashboards, and an intuitive user interface.

## 🚀 Features

- User Registration & Login
- Secure Authentication using JWT
- Create, Update, Delete Tasks
- Task Status Management
- Dashboard with Task Overview
- Calendar-based Task Tracking
- Responsive User Interface

## 🛠️ Technologies Used

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt

### Tools
- Git
- GitHub
- Postman
- Visual Studio Code

## 📁 Project Structure

```
TaskFlow

```

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/kaushaliyaparathne/TaskFlow.git
```

### Install Frontend

```bash
cd frontend
npm install
npm run dev
```

### Install Backend

```bash
cd backend
npm install
npm start
```
